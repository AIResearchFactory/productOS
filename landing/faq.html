Frequently Asked Questions

Everything you need to know about ProductOS pricing, local AI models, security, and product management workflows.

Is ProductOS free?

ProductOS is 100% free and open-source under the MIT license. There are no paid tiers, subscriptions, or credit card requirements. You own your code and workspace completely.

How does ProductOS handle data privacy?

ProductOS is local-first. All your project files, notes, meeting transcripts, and AI conversation logs are saved directly to your local file system as plain Markdown files. Master encryption keys are stored securely in your OS keychain (macOS Keychain, Windows Credential Manager, Linux Secret Service).

What is Silent Learner & Context Engine in ProductOS?

Silent Learner is ProductOS's autonomous local context engine. It continuously listens to your project workspace, meeting notes, and PRD updates while you work—building a private local knowledge layer without requiring manual dataset tagging, training, or constant copy-pasting.

Can I run local LLMs with ProductOS?

Yes! You can connect local AI runners like Ollama or LM Studio. ProductOS routes your prompts directly to local HTTP endpoints (e.g. localhost:11434), giving you 100% offline, private AI intelligence without sending a single byte to the cloud. It features hybrid routing to use fast local models for project memory and cloud LLMs for complex reasoning.

How is ProductOS different from standard web AI tools (ChatGPT / Claude web)?

Standard web interfaces lack persistent local context and project file organization. ProductOS automatically organizes your workspace into projects, binds local document context to prompts, supports visual drag-and-drop workflow automations, and lets you switch between Claude, GPT-4, Gemini, and Ollama seamlessly in one UI.

Does ProductOS support Model Context Protocol (MCP) integrations?

Yes. ProductOS natively supports MCP, enabling your local AI workspace to connect to external developer and productivity tools such as Jira, GitHub, Notion, and Slack for live data queries and workflow actions.

What operating systems are supported?

ProductOS is cross-platform. We provide official release binaries for macOS (Universal binary for Apple Silicon M1/M2/M3/M4 & Intel), Windows 10/11 (64-bit installer), and Linux (.AppImage, .deb, .rpm).
