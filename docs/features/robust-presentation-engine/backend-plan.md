# Backend Plan: Robust & Brand-Aware Presentation Engine

## 1. Node Backend Responsibilities
1. **Brand Settings & Template Storage**:
   - Extend Project Service (`node-backend/lib/services/project-service.mjs`) to persist `brandConfig` and template metadata inside `.metadata/project.json`.
   - Store uploaded sample `.pptx` or `.potx` decks in `{PROJECTS_DIR}/{projectId}/templates/sample_deck.pptx`.
2. **Template Upload & Processing Service**:
   - Endpoint: `POST /api/projects/:projectId/presentation/template` (accepts `.pptx` or `.potx` multipart file).
   - Endpoint: `POST /api/projects/:projectId/presentation/export-template`
   - Service: `node-backend/lib/services/pptx-template-service.mjs`
   - Uses native `yauzl` / `jszip` to extract sample `.pptx` / `.potx` archives.
   - Duplicates slide XML files (`ppt/slides/slideN.xml`) and updates `<p:sldIdLst>` in `ppt/presentation.xml`.
   - Replaces placeholder tokens (`{{TITLE}}`, `{{BULLETS}}`, `{{METRIC}}`) in OOXML `<a:t>` tags while preserving theme colors and master layouts.
   - Runs relationship cleaner to prune orphaned rels/media and zips output presentation.

## 2. API Specifications

### `GET /api/projects/:projectId/brand`
**Response**:
```json
{
  "colors": {
    "primary": "0F172A",
    "secondary": "10B981",
    "accent": "06B6D4",
    "backgroundLight": "F8FAFC",
    "backgroundDark": "0F172A"
  },
  "typography": {
    "headingFont": "Inter",
    "bodyFont": "Inter"
  },
  "hasCustomTemplate": true,
  "templateFileName": "sample_deck.pptx"
}
```

### `POST /api/projects/:projectId/presentation/export-template`
**Payload**: `{ slides: SlideData[] }`
**Response**: Binary `.pptx` file stream generated by duplicating and filling template slides.
